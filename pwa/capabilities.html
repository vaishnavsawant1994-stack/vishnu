What Vishnu can do

Vishnu combines a conversational assistant with memory, knowledge, specialist agents, governed tools, devices, and research labs. This guide explains what is in the project and what each part needs before you can use it.

How to read this page: “In the codebase” means the system has an implementation. It does not guarantee the feature is enabled on this device. Some features need setup, owner approval, an external provider, or further platform testing. This page does not grant permissions or activate tools.

Skills

Reusable action recipes, not extra permissions.

Skill-learning system · experimental

The repository includes an experimental system that can represent a skill as a declarative plan from an explicit list of allowed actions, evaluate it, and route real actions through Vishnu’s normal governance. The audit does not establish a fixed, user-facing catalog of ready-made skills. A learned recipe cannot grant itself a new tool or bypass approval.

ExperimentalNo permission bypass

Infrastructure for designing and qualifying governed capabilities, with staged side effects and approval boundaries. It is gated and does not enable unrestricted self-modification.

Reverse engineering: REA

Reverse Engineer Anything, connected through a bounded MCP integration.

What the connection does

When the pinned REA runtime is installed and running, Vishnu can read REA’s live MCP tool catalog and project its advertised operations through Vishnu’s ToolRegistry. The specific operations available depend on that live catalog and on REA’s provider prerequisites.

  • Vishnu keeps its normal owner permissions, approvals, emergency stop, and audit around projected tools.
  • Read-only, destructive, and other side-effecting operations use their declared risk floor; unknown risk fails closed.
  • Target-derived code, logs, scripts, network data, and file content are treated as untrusted input.
  • Analysis engines may require separate software, hardware, isolation, or commercial licenses. Vishnu does not supply those automatically.
