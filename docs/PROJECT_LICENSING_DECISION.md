# Project Licensing Decision

Reviewed: 2026-10-15

## Decision

Vishnu remains a proprietary project with all rights reserved. No open-source license or general third-party reuse permission is granted.

This decision preserves the current ownership position while the product is developed for a potential commercial offering. It does not grant customers or the public rights to copy, modify, redistribute, sublicense, commercially exploit, or create derivative works from the Vishnu project source except under a separate written agreement or where non-waivable law independently provides a right.

The repository is public on GitHub. Public visibility does not make Vishnu an open-source project or grant a general software license. The root `LICENSE` file now records the proprietary all-rights-reserved position. Third-party materials remain governed by their own licenses and notices, including the notices maintained in `THIRD_PARTY_NOTICES.md` and related compliance documentation.

The root `SECURITY.md` defines the private vulnerability-reporting and authorized-testing baseline. It does not grant a bug-bounty promise, security-testing authority over third-party systems, or additional rights to the proprietary Vishnu code.

Before external source or binary distribution, the owner must confirm contributor and third-party rights, include required dependency and asset notices, and approve customer-facing commercial terms. If the intended model changes to open source, select and apply an appropriate standard license only after confirming the project has authority to grant those rights.

This is a project policy record, not legal advice.
